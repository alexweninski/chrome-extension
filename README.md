Uses html, css and js to create a chrome extension that lets you block websites of your choice. I created it because I want to block sites like youtube, but sometimes I have legitimate reasons for going on them, like going on youtube to study or to follow someone on instagram. So I created this extension that lets you configure what websites you want to block, and then when you go on the website, it is blocked and you are prompted to give a justification and a time limit. Those items are sent to an LLM and it decides whether or not the website can be unblocked. It will not be published and it requires you to bring your own openai api token.
